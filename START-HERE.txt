============================================================
  PocketOffice v1.4.0 — how to run it on a restricted PC
============================================================

WHAT IT IS
  A complete office suite that runs inside a web browser.
  No installation. No admin rights. No internet needed.
  Six tools: Writer, Calc, Impress, Text Editor, PDF Tools,
  Markdown. Writer, Calc, Impress and the Text Editor all
  support MULTIPLE documents at once — every open document
  gets its own tab, and tabs are remembered between runs.

------------------------------------------------------------
STEP 1 — Copy this whole "PocketOffice" folder to the PC
------------------------------------------------------------
  USB stick, Desktop, Documents — anywhere you can write.
  The folder must contain: start.bat, index.html, css/, js/, lib/

------------------------------------------------------------
STEP 2 — Open it (pick ONE method)
------------------------------------------------------------

  EASIEST:  double-click  start.bat
            (it finds Microsoft Edge or Google Chrome for you and
             opens PocketOffice, even if .html files are locked)

  ALSO WORKS:  double-click  index.html
               (opens in your default browser)

  IF NEITHER WORKS:

  Option A — Drag-and-drop
    * Open Microsoft Edge (Start menu → type "Edge")
    * Drag  index.html  from this folder onto the Edge window

  Option B — Paste the file path
    * Hold SHIFT, right-click index.html, choose "Copy as path"
    * Open Edge, paste into the address bar, press Enter
    * It will look like:  file:///E:/PocketOffice/index.html

  You should see the PocketOffice tab strip with 6 tools.

------------------------------------------------------------
STEP 3 — Use it
------------------------------------------------------------
  * Click any of the 6 tabs at the top:
      Writer        word processor
      Calc          spreadsheet (with charts)
      Impress       slide presentations
      Text Editor   plain text / code
      PDF Tools     open & view PDFs
      Markdown      live-preview markdown editor

  * MULTIPLE DOCUMENTS: Writer, Calc, Impress and Text Editor
    each have a tab strip under the toolbar. ＋ New (toolbar or
    tab strip) opens a fresh document in a new tab; the ✕ on a
    tab closes it (asking first if there is unsaved work).
    Tabs can be DRAGGED to reorder. Ctrl+Shift+T reopens the
    last closed tab. Tabs are restored the next time you open
    PocketOffice.

  * FONTS: Writer and Impress offer 18 system fonts plus
    Inter, Lora and JetBrains Mono — these three are bundled
    in the folder (lib/fonts), so they look the same on any
    PC, even offline. PDF exports embed these three families.

  * Open and save real files with the toolbar buttons
    (Open… / Save / Save As…). Files go wherever you pick.

  * Everything also AUTOSAVES to the browser, so closing the
    tab by accident loses nothing.

  * Keyboard:  Alt+1..6 switches tools.
               Ctrl+Shift+T reopens a closed tab.
               Ctrl+Shift+D toggles dark mode.
               Ctrl+S saves the current document.

------------------------------------------------------------
TROUBLESHOOTING
------------------------------------------------------------
  * "Blank page / nothing happens"
      → Use Edge or Chrome. Other browsers may not support
        the File System Access API needed for native Save.

  * "Edge won't open local files"
      → Some IT policies block file:// in browsers. If that
        happens, ask IT to allow it, OR run PocketOffice from
        a simple local folder you have write access to.

  * "Save downloaded a file instead of opening a dialog"
      → That's the automatic fallback; it still works. The
        file lands in your Downloads folder.

------------------------------------------------------------
PRIVACY
------------------------------------------------------------
  100% local. No data leaves this PC. No telemetry. No
  accounts. Every library and font is bundled in the "lib"
  folder.
